## Архитектура

`routes.py` → `algorithms/*.py` → `views/*_practice.tpl`

- Алгоритмы бросают **`ValueError` с русским текстом** при невалидных данных.
  Маршрут ловит `ValueError` и `Exception`, пишет в `error`.
- Все данные для шаблона готовятся в `routes.py` — шаблоны модули **не импортируют**.
- JSON для vis.js передаётся через `result['gv']`, `result['ge']` и т.п.
  (сериализуется в `routes.py` через `json.dumps`, вставляется через `{{!...}}`).
- Логирование каждого запуска: `_save_log(page, input, result)` → `data/<page>_log.json`.
  Ошибки лога не прерывают основной поток (`try/except pass`).

## Структура шаблонов (не нарушать)

Каждый `*_practice.tpl` состоит из трёх секций-комментариев:
```
<!-- СЕКЦИЯ 1: Форма ввода -->
<!-- СЕКЦИЯ 2: Ошибка      -->  % if error:
<!-- СЕКЦИЯ 3: Результат   -->  % if result:
```
Шаблоны начинаются с `% rebase('layout.tpl', ...)`.
`{{переменная}}` — с эскейпингом, `{{!переменная}}` — сырой HTML/JSON.

## Ключевые соглашения

**CSS:** цвета `#1a3a5c` / `#2e86ab`. Кастомные стили — только `static/content/site.css`.
**JS:** глобальные функции — только `static/scripts/graph-input.js`.
**Bootstrap 3 и jQuery — локальные файлы, CDN не использовать.**

**Git:** все коммиты **только на русском** (или только на английском — не смешивать).
`README` и `data/*.json` — в `.gitignore`. `data/.gitkeep` — в репозитории.
Название решения: `BottleWebProject_С326_STEP.sln`.

**Тесты:** `unittest`, файлы `test*.py` в `tests/`. Минимум **2 тест-класса, 5 тест-кейсов**
на каждый алгоритм. Тесты проверяют только `algorithms/*.py`, не маршруты.

**Код:** PEP 8, `snake_case`, отступы 4 пробела, строки до 100 символов.

## Поведение перед выполнением задачи

Если задача затрагивает **2+ модуля**, требует изменения контракта алгоритма,
затрагивает `routes.py` + шаблоны одновременно, или несёт риск поломки
зависимостей — сначала перечисли несостыковки и предложи план по шагам,
**жди подтверждения**.

Для **простых изменений в одном файле** — выполняй сразу, но флагуй найденные
проблемы по ходу.

Если в промпте что-то **противоречит коду** (другие имена функций, другой формат
возврата, несуществующие переменные в шаблоне) — **уточни, не угадывай**.
