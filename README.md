# BottleWebProject_С326_1_STEP

## Описание проекта

Многостраничное веб-приложение для решения задач математического моделирования на графах. Реализовано на веб-фреймворке **Bottle** (Python 3.8+). Приложение позволяет пользователю через браузер вводить исходные данные (графы, веса, зависимости) и получать результат решения соответствующей задачи с сохранением истории вычислений.

## Используемое ПО

| Компонент | Версия | Назначение |
|-----------|--------|-------------|
| Python | 3.8+ | Интерпретатор языка |
| Bottle | 0.13+ | Веб-фреймворк для маршрутизации и шаблонов |
| unittest | встроенная | Модульное тестирование |
| Visual Studio Community | 2022 | Среда разработки (рекомендуется) |

## Решаемые задачи

Приложение содержит четыре независимых метода (каждый на отдельной странице):

| Метод | Алгоритм | Входные данные | Выходные данные |
|-------|----------|----------------|-----------------|
| **Маршрутизация в компьютерных сетях** | Модифицированный Дейкстра (обработка `inf`) | Ориентированный граф (N≤20), веса ≥1 или `inf`, узел-назначения | Для каждой вершины: минимальная задержка до цели и маршрут |
| **Анализ устойчивости транспортной сети** | Тарьян (мосты) + Флойд–Уоршелл | Неориентированный взвешенный граф (N≤20, веса положительные) | Список мостов, изменение суммарной длины кратчайших путей после удаления каждого моста |
| **Расчёт критического пути (CPM)** | Топологическая сортировка + DP | Ориентированный ациклический граф (N≤20), веса на вершинах, список зависимостей | Общая длительность проекта, список вершин критического пути |
| **Автоматическое составление расписания** | Жадная раскраска + локальная оптимизация | Неориентированный граф конфликтов (N≤20), дисциплины с указанием преподавателя | Минимальное число смен, распределение дисциплин, смены каждого преподавателя |

## Запуск приложения

### Способ 1. Из командной строки

```bash
python app.py
```

### Способ 2. Из Visual Studio Community 2019

1. Открыть файл решения `BottleWebProject_С326_1_STEP.sln`
2. Установить пакеты (если требуется): `pip install -r requirements.txt`
3. Нажать `F5` (Start Debugging) или `Ctrl+F5` (Start Without Debugging)
