# Отчет о тестировании четвертого варианта

## Объект тестирования

Страница `Раскраска графа - практика` и основная логика автоматического составления расписания.

## Unit-тесты

Файл: `tests/test_coloring.py`.

Проверяются:

- валидация дисциплин и преподавателей;
- валидация конфликтов;
- удаление пустых и повторяющихся конфликтов;
- построение неориентированного графа;
- жадная раскраска;
- расписание для графов без конфликтов, цепочки, треугольника и полного графа;
- расчет смен преподавателей;
- импорт JSON;
- обратная совместимость экспортированного JSON;
- случайная генерация данных.

Команда запуска:

```bash
python -m unittest discover -s tests -p "test_*.py"
```

## Selenium/UI-тесты

Файл: `tests/test_coloring_ui.py`.

Проверяются:

- наличие основных элементов страницы практики;
- импорт данных из JSON;
- ручное добавление дисциплины после импорта;
- ручное добавление конфликта после импорта;
- расчет расписания после ручного редактирования;
- появление блока результата;
- появление canvas интерактивного графа;
- случайная генерация дисциплин.
- ошибка при избыточном количестве дисциплин.

Selenium-тест сам запускает Bottle-сервер на свободном локальном порту. Если Selenium или браузерный драйвер не установлен, тест помечается как пропущенный, чтобы unit-тесты основной логики не ломались.

Отдельный запуск UI-теста:

```bash
python -m unittest tests.test_coloring_ui
```

| TC_UNIT_3 | Конфликт с неизвестной дисциплиной | Ошибка валидации |
