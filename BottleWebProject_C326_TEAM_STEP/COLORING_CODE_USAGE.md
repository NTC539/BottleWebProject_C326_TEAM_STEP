# Четвертый вариант: как работает код и как пользоваться страницей

## Назначение

Четвертый вариант решает задачу автоматического составления расписания через раскраску графа.

В программе:

- дисциплина - вершина графа;
- конфликт между дисциплинами - ребро графа;
- смена - цвет вершины;
- конфликтующие дисциплины не должны попасть в одну смену.

Алгоритм оставлен по заданию: жадная раскраска Welsh-Powell и локальная оптимизация.

## Где находится код

### `algorithms/coloring.py`

Файл содержит основную логику четвертого варианта.

Основные функции:

- `sample_coloring_data()` возвращает демонстрационные дисциплины и конфликты для первого открытия страницы.
- `load_coloring_json(data)` читает данные из JSON и проверяет их.
- `make_export_data(subjects, conflicts, result)` собирает данные для скачивания результата в JSON.
- `generate_random_data(count, density)` создает случайный набор дисциплин и конфликтов.
- `solve_coloring(subjects, conflicts)` запускает расчет расписания.
- `check_input(subjects, conflicts)` проверяет дисциплины и конфликты.
- `make_graph(vertices, conflicts)` строит неориентированный граф.
- `sort_vertices(vertices, graph)` сортирует вершины по степени.
- `greedy_coloring(order, graph)` выполняет жадную раскраску.
- `compact_schedule(...)`, `reduce_color_count(...)`, `optimize_teachers(...)` улучшают результат в рамках локальной оптимизации.
- `make_schedule(subjects, colors)` формирует таблицу расписания по сменам.
- `make_teacher_table(colors, teachers)` формирует таблицу смен преподавателей.

Функция `solve_coloring()` возвращает словарь с результатом:

```python
{
    "subjects": subjects,
    "num_colors": 2,
    "colors": {"Математика": 1, "Физика": 2},
    "schedule": [],
    "teacher_shifts": [],
    "teacher_cost": 0,
    "order": [],
    "degrees": {},
    "conflicts": []
}
```

### `routes.py`

В файле находится маршрут страницы практики:

```python
@route('/coloring/practice', method=['GET', 'POST'])
```

Маршрут работает по значению скрытого поля `form_action`.

Действия:

- `calculate` - читает данные из формы, считает расписание и показывает результат.
- `generate` - создает случайные данные.
- `load_json` - загружает данные из JSON-файла.
- `export_json` - пересчитывает текущие данные и скачивает JSON с результатом.

Вспомогательные функции:

- `_read_coloring_form()` читает дисциплины и конфликты из формы.
- `_export_coloring_json(...)` отдает JSON-файл на скачивание.
- `_save_coloring_history(...)` сохраняет историю расчета в `data/coloring_history.json`.

### `views/coloring_practice.tpl`

Это шаблон страницы практики.

На странице есть:

- таблица дисциплин;
- список конфликтов;
- блок импорта JSON;
- блок случайной генерации;
- кнопка расчета расписания;
- интерактивная область графа;
- блок результата после расчета.

Данные дисциплин отправляются такими полями:

```text
subject[]
teacher[]
```

Данные конфликтов отправляются такими полями:

```text
conflict_from[]
conflict_to[]
```

### `static/scripts/coloring_practice.js`

Файл отвечает за поведение страницы в браузере:

- добавляет и удаляет дисциплины;
- обновляет номера строк;
- обновляет выпадающие списки конфликтов;
- добавляет и удаляет конфликты;
- меняет скрытое поле `form_action` перед отправкой формы;
- строит интерактивный граф через `vis-network`;
- обновляет граф после изменения дисциплин и конфликтов;
- подсвечивает вершины после расчета.

### `tests/test_coloring.py`

Unit-тесты основной логики.

Они проверяют:

- валидацию входных данных;
- построение графа;
- раскраску;
- расписание;
- импорт и экспорт JSON;
- случайную генерацию.

### `tests/test_coloring_ui.py`

Selenium/UI-тесты страницы практики.

Они проверяют:

- открытие страницы;
- наличие основных элементов;
- импорт JSON;
- ручное редактирование после импорта;
- расчет результата;
- отображение графа;
- случайную генерацию.

## Формат JSON для импорта

JSON должен содержать поле `subjects`.
Поле `conflicts` можно оставить пустым списком.

Пример:

```json
{
  "subjects": [
    { "name": "Математика", "teacher": "Иванов" },
    { "name": "Физика", "teacher": "Петров" },
    { "name": "Информатика", "teacher": "Сидорова" }
  ],
  "conflicts": [
    ["Математика", "Физика"],
    ["Физика", "Информатика"]
  ]
}
```

Экспортированный JSON тоже можно загрузить обратно.
Поле `result` при импорте игнорируется, а `subjects` и `conflicts` используются как исходные данные.

## Проверки входных данных

Программа проверяет:

- список дисциплин не должен быть пустым;
- у дисциплины должно быть название;
- у дисциплины должен быть преподаватель;
- названия дисциплин не должны повторяться;
- количество дисциплин не должно быть больше `20`;
- конфликт должен содержать две дисциплины;
- обе дисциплины из конфликта должны существовать в списке дисциплин;
- повторяющиеся конфликты не дублируются;
- конфликт дисциплины с самой собой игнорируется.

Если есть ошибка, страница показывает сообщение над формой.

## Как пользоваться страницей

1. Открыть страницу:

```text
http://127.0.0.1:5555/coloring/practice
```

2. Заполнить дисциплины.

В таблице `Дисциплины` нужно указать название дисциплины и преподавателя.
Новую строку можно добавить через поля под таблицей и кнопку `Добавить`.

3. Добавить конфликты.

В блоке `Конфликты` выбрать две дисциплины из списков и нажать `Добавить`.
Конфликт означает, что эти дисциплины нельзя поставить в одну смену.

4. При необходимости загрузить JSON.

В блоке `Импорт из JSON` выбрать файл и нажать `Загрузить JSON`.
После загрузки данные можно редактировать вручную.

5. При необходимости сгенерировать данные.

В блоке `Случайная генерация` указать:

- количество дисциплин;
- плотность графа от `0` до `1`.

После нажатия `Сгенерировать данные` таблицы будут заполнены автоматически.

6. Посмотреть граф.

Граф отображается в блоке `Граф конфликтов`.
Его можно перемещать и масштабировать мышью.

Кнопки:

- `Уместить` возвращает граф в видимую область;
- `Расположить` запускает авторазмещение заново.

7. Рассчитать расписание.

Нажать `Рассчитать расписание`.
После расчета появится блок `Результат`.

В результате выводятся:

- количество смен;
- штраф по сменам преподавателей;
- количество конфликтов;
- расписание по сменам;
- смены преподавателей;
- порядок обработки вершин.

8. Скачать результат.

После расчета появляется кнопка `Скачать JSON`.
Она скачивает файл вида:

```text
coloring_result_YYYYMMDD_HHMMSS.json
```

Этот файл можно использовать как результат работы и как входной файл для повторного импорта.

## Как запускать тесты

Запуск всех тестов:

```bash
python -m unittest discover -s tests -p "test_*.py"
```

Запуск только unit-тестов логики:

```bash
python -m unittest tests.test_coloring
```

Запуск только Selenium/UI-тестов:

```bash
python -m unittest tests.test_coloring_ui
```

Если Selenium или браузерный драйвер не установлен, UI-тест будет пропущен.
